# Contributing to the Mergington High Extra-Curricular Activities Website

Thank you for your interest in helping improve our school's website!

## Development Setup

1. Clone the repository to your computer.
2. Install Python requirements using `pip install -r requirements.txt`.
3. Run the development server using `python src/app.py`.
4. Visit `http://localhost:8000` in your browser.

## Making Changes

1. Create a new branch for your changes.
2. Make your changes and test them locally.
3. Push your branch and create a pull request.
4. Wait for review and address any feedback.

## Code Style

- Follow PEP 8 for Python code.
- Use clear, descriptive variable names.
- Add comments to explain blocks of logic.

## Need Help?

- Check the open issues first.
- Create a new issue if your problem has not been reported.
- Ask for help if you get stuck.
