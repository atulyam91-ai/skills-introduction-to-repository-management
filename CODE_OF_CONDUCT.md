# Mergington High School Code of Conduct

## Our Pledge

We pledge to make participation in this project a respectful and harassment-free experience for everyone.

## Our Standards

Positive behavior includes:
- Using welcoming and inclusive language.
- Respecting different viewpoints and experiences.
- Accepting constructive criticism gracefully.
- Focusing on what is best for the school community.
- Showing empathy toward others.

Unacceptable behavior includes:
- Using inappropriate language or imagery.
- Trolling, insulting comments, or personal attacks.
- Harassment in public or private.
- Sharing private information without permission.

## Responsibilities

Project maintainers are responsible for clarifying these standards and taking fair action when necessary.

## Scope

This Code of Conduct applies to project spaces and public spaces when someone represents the project or school.

## Enforcement

Report abusive or unacceptable behavior to the IT Club faculty advisor. Complaints will be reviewed promptly and fairly.
